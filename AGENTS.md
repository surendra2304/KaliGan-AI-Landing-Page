# KaliGan AI Landing Page

This repository contains the official landing page for **KaliGan AI** — human-like AI employees for calls, chat, scheduling, and back-office work, operating 24/7.

## Tech Stack
- **Framework:** TanStack Start v1 (React 19 + Vite 8 + file-based routing)
- **Styling:** Tailwind CSS v4 + custom design tokens in `src/styles.css`
- **Animation:** Framer Motion + Lenis smooth scroll + CSS keyframes
- **Deployment:** Vercel
