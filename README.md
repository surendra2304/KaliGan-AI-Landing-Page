# 🚀 KaliGan AI — Landing Page

> **Live Demo:** [Deploying to Vercel...]

**KaliGan AI** deploys human-like AI employees for calls, chat, scheduling, and back-office operations — working 24/7 with zero downtime.

---

## ✨ Key Features

- **Hero Animation:** Full-bleed interactive background video with split headline layout.
- **AI Employees Showcase:** Glassmorphism cards featuring dynamic interactive audio waveforms.
- **Voice & Chat Solutions:** Interactive cards showcasing multi-modal AI agent capabilities.
- **Smooth Animations:** Powered by Framer Motion & Lenis smooth scrolling.
- **Responsive & Modern:** Built with Tailwind CSS v4 and bespoke design system tokens.

---

## 🛠️ Tech Stack

- **Framework:** [TanStack Start](https://tanstack.com/router) (React 19 + Vite 8)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com)
- **Animations:** [Framer Motion](https://www.framer.com/motion/) + [Lenis](https://lenis.darkroom.engineering/)
- **Icons & UI:** Lucide React + Radix UI Primitives
- **Deployment:** [Vercel](https://vercel.com)

---

## 🚀 Local Development

### Prerequisites

- Node.js 18+
- npm

### Installation & Run

1. Clone the repository:
   ```bash
   git clone https://github.com/surendra2304/kaligan-ai-landing-page.git
   cd kaligan-ai-landing-page
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start dev server:
   ```bash
   npm run dev
   ```

4. Build production bundle:
   ```bash
   npm run build
   ```
